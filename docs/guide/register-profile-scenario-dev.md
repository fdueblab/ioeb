# 从注册到算法模型想定式开发使用指南

## 适用对象与前置条件

本指南面向首次使用平台的新用户，覆盖从账号注册、登录、用户画像完善到“算法模型想定式开发”模块完整操作流程。

::: warning 权限说明
“算法模型想定式开发”模块仅对具备 `publisher`（发布者）权限的账号开放。若你登录后看不到该菜单，请联系管理员分配权限。
:::

## 第一步：注册账号

![注册页面](/images/guide/register-profile-scenario-dev/注册.png)

1. 打开登录页，点击“注册”进入注册页面。
2. 按提示填写注册信息：
   - 用户名（必填，3-50 字符）
   - 姓名（选填）
   - 密码（必填，至少 6 位）
   - 确认密码（必填，需与密码一致）
3. 点击“注册”，成功后会提示“注册成功”，并跳转回登录页。

> 当前注册流程以账号密码为主，不包含短信验证码流程。


## 第二步：登录平台

![登录页面](/images/guide/register-profile-scenario-dev/登录.png)

1. 选择“账户密码登录”。
2. 输入用户名/邮箱与密码。
3. 点击“登录”，成功后进入平台。

## 第三步：首次登录完成用户画像问卷

首次登录后，若当前账号尚未完善画像，系统会自动弹出“用户画像问卷”。
![用户画像问卷](/images/guide/register-profile-scenario-dev/完善用户画像1.png)

你可以：

- 直接选择领域、专业、职业、技术需求并保存；
- 或先点击“跳过”，稍后在个人设置里补充。

问卷中支持上传简历（pdf/docx/txt/md）做自动识别预填。


## 第四步：在个人设置中补充用户画像

进入方式：

- 右上角头像下拉 -> 个人设置 -> 用户画像；
- 或在左边菜单栏点击个人中心 -> 个人设置 -> 用户画像。
![用户画像更改补充](/images/guide/register-profile-scenario-dev/完善用户画像2.png)

可维护内容包括：

- 领域
- 专业
- 职业
- 技术需求（多选）
- 个人简介

页面会展示画像完善度进度条，保存后会在右上角头像区域同步显示完善度。


## 第五步：进入“算法模型想定式开发”

从左侧菜单进入对应垂域的“算法模型想定式开发”：

![想定式开发-配置区](/images/guide/register-profile-scenario-dev/算法生成配置.png)

页面核心输入区包含：

- 基础信息：领域、算法模型名称（必填）、行业、场景、技术
- 数据与类别：数据集文件、算法类别（及类别参数）
- 相关资料：论文/专利/代码等参考材料上传
- 自由叙述：详细描述你的需求目标（必填）

点击“生成算法模型”后，系统会展示智能体执行进度与生成结果。


## 第六步：查看生成进度与结果

生成过程中可以查看“智能体执行步骤”。
![生成进度](/images/guide/register-profile-scenario-dev/算法生成智能体执行过程.png)

生成完成后，重点查看以下结果页签：

- 下载与资源库：下载生成代码，查看资源库提示
![结果Tab预览](/images/guide/register-profile-scenario-dev/生成结果输出1.png)
- 测试结果：查看各维度验证状态
![测试结果](/images/guide/register-profile-scenario-dev/生成结果输出2.png)
- 参考资料：查看引用与参考摘要
![参考资料](/images/guide/register-profile-scenario-dev/生成结果输出3.png)
- 差异化说明：查看新增点、改进点、优势说明

## 常见问题

### 1) 为什么“生成算法模型”按钮是灰色的？

通常是“算法模型名称”或“自由叙述”未填写。请先补齐必填项。

### 2) 为什么看不到“算法模型想定式开发”菜单？

当前账号权限可能不是 `publisher`。请联系管理员开通。

### 3) 上传文件后没有触发预期效果怎么办？

请先确认文件格式是否受支持，并尽量使用结构清晰的文件（例如可复制文本的 PDF/DOCX）。

### 4) 生成失败怎么办？

优先检查：网络连接、输入描述是否过于简略、上传文件是否异常。必要时补充更明确的自由叙述后重试。
